# Validation v1 input construction

Mode: Codex built-in image generation, one independent job per case. Exact prompts: `generation-plan.json`; returned job paths: `generation-results.json`; rejected Yellow candidates and replacements: `replacement-plan.json`.

Only the canonical fictional identity was supplied as a reference. No Development case was an edit target or reference. Input admission checks identity, product absence, anatomy and measured pose; no product-edit output, provider, workflow or parameter was selected using this set. This is a local hash-sealed Validation input set, not a pinned inference benchmark or Formal dataset.
