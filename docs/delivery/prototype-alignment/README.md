# 原型结构与界面修正 — 2026-09-07

原来的本地版直接进入独立编辑器，缺少原型的全局导航和生产概览。本次以用户提供的
深色侧栏截图为视觉依据，恢复统一侧栏、顶栏、紧凑卡片和页面层级；原有编辑器进入
“生成工作台”。登录仍为独立入口，账号设置移到顶栏账号菜单。

## 已接入的页面

- `/#/dashboard`：真实本地任务队列、素材目录数量、最新人工审核的五维分布和任务异常。
- `/#/cases`：开发案例列表、编号搜索、交互类型筛选、姿态与视角匹配状态。
- `/#/cases/DEV_MOUTH_001/studio`：原有定位、遮挡、草稿、模板、预览、处理任务和保存历史。
- `/#/review`：跨案例的已完成结果、五维人工审核、审核历史及结果/证据下载。
- `/#/assets`：实际 Case Base 和商品视角图片、数据集校验来源。
- `/#/algorithms`：实际保存的定位模板及版本。
- `/#/analytics`：本地任务数量与人工审核统计。
- `/#/trace`：跨案例任务列表、状态筛选、分页和结果/证据入口。

Preflight、模型与工作流、正式批量测试保留原型入口，并明确标记未接入。Trace 当前
提供本地任务与审核证据，不宣称完整生产 Replay 已实现。Canonical Base 尚无独立
前端目录。Technical Pass、Attempt 1 Pass、平均人工处理用时没有数据，显示“—”。
没有沿用原型的 56%、44%、5m12s 等演示指标。

## 行为与数据

切换主导航保留已打开工作台的未保存参数；切换案例继续使用原有保存/放弃/取消流程。
取消切换时同步恢复当前案例的地址，支持刷新、浏览器前进后退和案例链接直达。

`GET /api/v1/development/studio/jobs/summary` 汇总本地任务；五维比例只取每个已完成结果
的最新人工审核版本，保留审核哈希链检查。没有审核时返回 null，不显示为 0% 或合格。
任务列表支持省略 case_id，并按 state、limit、offset 查询；原有单案例查询兼容。
所有新接口继续受原有登录与服务端权限约束。没有数据库结构变更。
