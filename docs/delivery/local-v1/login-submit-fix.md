# 登录提交与错误提示修复 — 2026-09-05

用户截图显示“请求失败，请检查输入”。API 日志记录两次登录 POST 返回 422（请求字段校验失败）。使用本机凭据文件执行登录、读取会话和退出均为 200，因此初始凭据可用。历史请求未保存字段内容，不能断言截图中的具体失败字段。

修复登录表单提交：通过 FormData 读取当前输入框的真实值，兼容未触发 React change 事件的自动填充；仅清除账号首尾空白，密码原样提交。将 FastAPI 字段校验、认证错误、连接失败和服务异常转换为明确提示，禁止回显校验响应中的 input（可能包含密码）。

验证：前端 10 项测试、类型/格式检查和构建通过。实际浏览器检查结果见 login-submit-check.json，涵盖非法账号提示、无 change 事件的填值提交、带首尾空格的账号、登录后会话及素材目录访问、退出后会话失效。测试使用独立浏览器会话，不修改账号密码。

本地 API 已更新，修正版交付包为 data/local-delivery/interaction-studio-local-v1.0.4.tar.gz。
