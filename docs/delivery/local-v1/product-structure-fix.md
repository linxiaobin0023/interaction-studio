# 奶嘴结构修正与当前质感限制 — 2026-09-05

用户指出合成中的奶嘴明显失真。核对参数模型发现，v1 吸嘴中心在 Y=0.73，长轴也沿 Y；这会在正面护盾上方形成白色凸起。产品由简化 SDF 几何和固定光照渲染，未形成照片级材质；单纯贴图也没有接触阴影。

本次新增本地商品母版 v2，将吸嘴中心移到护盾后方 Z=-0.58，长轴改为 Z 方向，与按钮同轴。沿用同一渲染器重新生成 11 个角度的五层素材，清单绑定 spec、renderer 和各层哈希。v1 及已封存 Development/Validation 数据保持原样，v2 仅用于可选择的本地开发预览，不改变原数据集对 v1 的引用。

新编辑默认采用“结构修正版”；旧草稿、模板、任务保留原素材版本，可在“交互设置 → 商品素材”切换后生成新结果。未传版本的旧接口请求仍使用 v1，保持历史请求兼容。保存、撤销、模板与任务绑定所选版本；旧输出不被替换。

v2 含咬合成加入低强度、局限于接触带内的几何阴影。手绘遮挡区域保持不变，靠近嘴部与手持场景不自动增加贴脸阴影。阴影只在“合成预览”及新任务结果中出现，定位编辑仍展示原始商品图层。

这次仅修复明确的结构错误并补充基础接触线索。当前仍是简化程序化产品，未实现真实硅胶折射、环境反射、场景光照匹配、口唇形变或自动语义遮挡，不能认定为照片级真实合成。模型接入仍按用户要求暂缓；视觉质量仍需后续改善，不因代码测试通过而判为合格。
