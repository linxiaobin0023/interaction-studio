# 登录布局修正 — 2026-09-05

用户截图暴露出登录卡片被挤在屏幕左侧的问题。根因是全局 `main` 选择器及其响应式规则
把工作台三栏布局应用到了登录页；此前类型检查和 HTTP 验证没有发现实际视觉缺陷。

修正：工作台布局限定为 `.app > main`；登录页使用独立单栏布局，卡片桌面宽度 440 px，
小屏保留 16 px 边距。补齐标题/正文/按钮间距，按钮整行显示，精简登录说明。

验证使用本地 Chromium 实际渲染 1912×948、768×1024、390×844、320×640 四种视口；
检查卡片在可用区域居中、宽度适配、无横向溢出和账号到密码的 Tab 顺序。
截图与测量结果记录在本目录的 `login-layout-*` 文件中。
仅登录页完成了本轮视觉/键盘验证，不代表编辑画布、完整审核流程已经过浏览器验收。

当前运行服务已更新；修正版源码包为 `data/local-delivery/interaction-studio-local-v1.0.1.tar.gz`。
旧 v1 包保留为历史版本。
