# Interaction Studio Prototype

## 打开方式

1. 解压 ZIP。
2. 保持 `index.html` 与 `assets/` 的相对目录不变。
3. 双击 `index.html` 即可本地评审。

## 说明

- 所有图片均为 Mock 素材。
- HTML 不再内嵌 Base64 图片。
- `assets/` 可以直接替换为后续甲方真实人物、Case Base、商品图片。
- 本原型用于冻结产品结构、角色、状态、Gate、接口边界与交互，不代表真实模型已达到页面中的演示指标。
